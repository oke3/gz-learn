# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-08-27

### Added
- 6-module curriculum covering prompt engineering, skills, agents, MCP, providers, and multi-agent workflows
- 18 lessons, each with objective, key concepts, and a practice prompt
- JSONL-based progress tracking (completed lessons, practice runs, metadata)
- Practice project scaffolder (AGENTS.md, TASK.md, opencode.jsonc)
- CLI with list, show, start, complete, practice, progress, status, reset, and health commands
- 37 tests covering curriculum, store, scaffold, and CLI
